You download Main.Lua, enabled.txt, and UE4SS_v4.0.0.zip
Go to your Win64 folder ex. A:\SteamLibrary\steamapps\common\Icarus\Icarus\Binaries\Win64
Extract your UE4SS folder into your Win64
Open UE4SS folder and select "Mods" then you create a folder called "CustomWaypoints"
Put enabled.txt into it and create a "Scripts" folder in that same folder(CustomWaypoints)
Finally, put the Main.Lua into the Scripts folder, path should look like this "A:\SteamLibrary\steamapps\common\Icarus\Icarus\Binaries\Win64\ue4ss\Mods\CustomWaypoints\Scripts"
Enjoy :D
